# Kripal Parsekar

Personal portfolio website for Kripal Parsekar, a DevOps and Infrastructure Engineer based in London, UK.

## Sections

- **About** — Background, contact info, and bio
- **Resume** — Education and work experience
- **Skills** — Technical skills across Languages, CI/CD, Cloud, and Monitoring
- **Projects** — Coming soon
- **Contact** — Email, phone, and social links

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- AOS (Animate On Scroll)
- Typed.js
- Bootstrap Icons, Boxicons

## Setup

Open `index.html` directly in a browser — no build step required.

To deploy, push to GitHub and enable GitHub Pages on the `main` branch.
